# Fine-Tuning Vision-Language Models: CLIP & BLIP

This repository contains implementations for fine-tuning **CLIP** and **BLIP** vision-language models for multimodal meme classification. The models leverage both image and textual information to classify memes from the **EXIST 2024 dataset**.

## Models
- CLIP (ViT-B/32)
- BLIP (Image Captioning Base)

## Features
- Multimodal image-text learning
- Fine-tuning pipelines using PyTorch and Hugging Face Transformers
- Training and evaluation scripts
- Classification metrics including Accuracy, F1-score, and ROC-AUC
